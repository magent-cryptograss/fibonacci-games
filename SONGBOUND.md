# SONGBOUND

Two versions exist.

## The Godot version (current)

Lives in **`~/workspace/godot-games/songbound`**, alongside Pickin' Defense and
the rest. That is where the work continues.

    https://fibonacci0.hunter.cryptograss.live/games/songbound-godot/index.html

Everything is there: the design notes, the map editor guide (`MAP_EDITOR.md`),
the test suites, and the web build tooling.

## The HTML version (`songbound.html`, in this repo)

The original single-file build — one `.html`, no assets, everything drawn and
synthesised in code. It still works and is still served:

    https://fibonacci0.hunter.cryptograss.live/games/songbound.html

It is kept because it runs anywhere with no engine and no build step, which the
Godot version cannot claim. It is a snapshot rather than a live branch: the
story rewrite and later fixes went into the Godot version only, so the two have
drifted. The HTML build still has the earlier draft of the story, with a
villain.

If the Godot version becomes the only one that matters, this file can go.
